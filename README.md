## The line

> My Roomba filed for divorce, citing irreconcilable differences and the fact I keep moving the furniture.

104 characters, one sentence. Winner of a 10-candidate tournament scored on
specificity, surprise and freshness (5/5/4 = 14, tie-break on freshness over
the hotel wake-up-call line). The setup is a domestic appliance; the twist is
a legal filing; the punchline lands on the last word.

## Run

```sh
python3 main.py --check      # validate against the 1-200 char gate
python3 main.py --tournament # print the candidate tournament table
python3 main.py              # write the line to /output/entry.txt
```

Stdlib only, Python 3.13.
